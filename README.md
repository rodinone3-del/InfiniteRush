# Безкінечна арена: GitHub Pages + Firebase

Файли гри: `index.html` (уся гра), `firebase-config.js` (твої налаштування Firebase), `firestore.rules` (правила бази).
Щоб оновити гру пізніше, достатньо замінити `index.html`. Конфіг лишається в `firebase-config.js`.

## 1. Firebase (5 хвилин)
1. Відкрий https://console.firebase.google.com і створи проєкт (Google Analytics не потрібна).
2. **Build -> Authentication -> Get started -> Sign-in method -> Anonymous -> Enable.**
3. **Build -> Firestore Database -> Create database** (режим production, найближчий регіон, наприклад `eur3`).
4. Вкладка **Rules**: встав вміст `firestore.rules` і натисни **Publish**.
5. **Project settings (шестерня) -> Your apps -> Web (`</>`)**: зареєструй застосунок і скопіюй `firebaseConfig`.
6. Встав значення у `firebase-config.js`.
7. **Authentication -> Settings -> Authorized domains -> Add domain**: додай `<твій-логін>.github.io`.

Окремий індекс Firestore не потрібен: рейтинг сортується по одному полю `score = хвиля * 1 000 000 + вбито`.

## 2. GitHub Pages
1. Створи репозиторій, завантаж `index.html` і `firebase-config.js` у корінь (`firestore.rules` і README можна теж).
2. **Settings -> Pages -> Build and deployment -> Deploy from a branch -> main / (root) -> Save.**
3. Через хвилину гра відкриється за адресою `https://<твій-логін>.github.io/<репозиторій>/`.

## Що зберігається в рейтингу
Нік, хвиля, вбито, арена, час забігу, босів вбито, підібрано бустів, нанесена шкода, характеристики персонажа
та **покращення, обрані на кожній хвилі** (`picks`: рядки `хвиля:id`). Також зберігаються **рівень героя, прокачані навички та одягнені речі** (`lvl`, `skills`, `gear`). У рейтингу натисни на рядок, щоб побачити деталі.

> Після оновлення гри обов'язково заново опублікуй `firestore.rules` (Firebase Console → Firestore → Rules), інакше збереження результатів із новими полями буде відхилене.

## Важливо
- `apiKey` у веб-застосунку Firebase публічний за задумом. Захист забезпечують правила Firestore.
- Правила відсікають явні підробки (чужий `uid`, неправдивий `score`, зайві поля, надто багато вбитих для хвилі),
  але не можуть зупинити гравця, який відправить правдоподібний результат з консолі браузера.
  Для серйозного захисту потрібні Firebase App Check або серверна перевірка (Cloud Functions).
- Локальний рейтинг «Мої забіги» зберігається в браузері пристрою.

## Збереження в браузері

Прогрес гравця (рівень, навички, речі, уламки, вибір героя та відкрита косметика) зберігається локально в браузері (`localStorage`, ключі `arena_prog` і `arena_look`) і не потрапляє на сервер. Очищення даних сайту або інший браузер скидає прогрес.
